การแข่งขันร้องเพลง

นี่คือหนึ่งในผลงานและความภาคภูมิใจที่เราได้เข้าร่วมแสดงความสามารถทางด้านดนตรี

ทักษะและการพัฒนาทางคอมพิวเตอร์

การประยุกต์ใช้เทคโนโลยีและการสร้างสรรค์ผลงานดิจิทัล รวมถึงการพัฒนาเว็บไซต์เบื้องต้น

ความสามารถทั่วไป

  • ร้องเพลง
  • เล่นกีตาร์
  • ทำอาหาร
  • ถ่ายรูป

ทักษะทางคอมพิวเตอร์

  • การพัฒนาเว็บไซต์: HTML, CSS เบื้องต้น
  • โปรแกรมสำนักงาน: Microsoft Word, Excel, PowerPoint
  • การสร้างสรรค์สื่อ: การตัดต่อวิดีโอ และการออกแบบกราฟิกเบื้องต้น
  • เทคโนโลยีทั่วไป: การสืบค้นข้อมูลออนไลน์ และการใช้งานระบบ Cloud
